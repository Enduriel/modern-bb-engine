# Natives the original binds that our engine doesn't have yet, found by the coverage
# probes menu/natives and campaign/natives (captured 2026-10-14): one per line, as
#   probe | key | reason
# like divergences.txt (a key with one '*' matches by prefix and suffix). It's a
# worklist: implementing a native makes its line stale, which fails the parity test until
# the line is removed.

# Not callable gaps: Sqrat puts a native `constructor` and `weakref` on every class. Ours
# makes native instances from Rust, and `weakref()` works through the default delegate.

menu/natives | native *.weakref | Sqrat class member
campaign/natives | native *.constructor | Sqrat class member
campaign/natives | native *.weakref | Sqrat class member
